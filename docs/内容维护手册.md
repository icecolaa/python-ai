# PythonAI 内容维护手册

> 适用场景：新增 Markdown 教程、修正图片路径、批量替换品牌词、重建资料库与手机离线包。
> 最近更新：2026-10-22。

## 1. 一键重建

资料库和手机版都由源文件生成，**不要直接改生成后的 HTML**（`PythonAI-学习资料库.html`、`outputs/` 下的文件），否则下次构建会被覆盖。

```bash
# 依赖（只需一次）
py -3.14 -m pip install Markdown lxml Pillow

# 重建资料库（根目录生成 PythonAI-学习资料库.html）
py -3.14 scripts/build_library_html.py

# 重建学习计划（课程表有变化时）
py -3.14 scripts/study_plan.py

# 打包手机离线版（读取上面两个 HTML）
py -3.14 scripts/export_mobile_html.py
```

如果本机默认 `python` 就是 3.10+ 且依赖齐全，把 `py -3.14` 换成 `python` 即可。构建日志里重点看三类信息：

- `Read ...: N sections, ...`：文档是否被读到；
- `image(s) inlined`：图片是否内联成功；
- `placeholder(s)`：是否有图片缺失（需要修复路径或补图）。

## 2. 新增 Markdown 教程

### 2.1 放置文件与图片

- Markdown 放在对应阶段的目录下，例如 `第2阶段：大模型技术核心/1_python编程基础与进阶/`。
- 图片统一放在该目录的 `code/images/` 下。
- 图片引用**相对于当前 Markdown 文件**，不是相对于仓库根目录：

```markdown
<!-- 文件：.../1_python编程基础与进阶/第3章：核心数据类型.md -->
![示意图](./code/images/31.jpg)
```

根目录的旧版单页 `Python编程基础与进阶-可视化文档.html` 是独立文件，图片要写成相对仓库根目录的路径：

```html
<img src="./第2阶段：大模型技术核心/1_python编程基础与进阶/code/images/31.jpg">
```

图片规则：单张不超过 3 MB 且路径存在时会被内联进 HTML；超过 3 MB、路径不存在或外链抓取失败时，会显示“插图暂缺”占位图。构建日志里的 placeholder 数量可用于快速检查。

### 2.2 注册到资料库

编辑 `scripts/build_library_html.py` 里的 `DOCS` 列表，新增一条：

```python
{
    "id": "doc-ch10",                       # 唯一 ID，学习计划也靠它跳转
    "group": "python",                      # 对应 GROUPS 里的分组
    "path": "第2阶段：.../第10章：xxx.md",   # 相对仓库根目录
    "nav_no": "10",
    "badge": "第 10 章",
    "short": "短标题",                       # 侧边栏显示
    "title": "完整标题",
    "desc": "一句话摘要，显示在首页卡片和搜索里。",
},
```

注意事项：

- `path` 必须真实存在，否则构建日志会打印 `Skip missing source`，页面不会出现该文档。
- 新增阶段或新分组时，先在 `GROUPS` 增加分组，再让 `DOCS` 的 `group` 指向它。
- 若原文自带一级标题、需要扁平化处理，加 `"heading_mode": "flatten_h1"`（参考“入门.md”）。
- 学习计划里的任务通过 `scripts/study_plan.py` 的 `doc-*` / `doc-*-sN` 关联文档锚点；新增章节若纳入计划，需要同步更新该脚本中的任务列表。

### 2.3 构建后检查

```bash
py -3.14 scripts/build_library_html.py
py -3.14 scripts/export_mobile_html.py
```

在浏览器打开 `PythonAI-学习资料库.html`，确认：左侧目录出现新章节、正文可滚动、图片正常、搜索能命中、手机版 `outputs/PythonAI-手机静态版/index.html` 可跳转。

## 3. 品牌词替换流程

### 3.1 替换映射

| 原内容 | 新内容 | 说明 |
| --- | --- | --- |
| `白泽` | `冰可乐` | 中文品牌名 |
| `baize` | `icecola` | 小写标识、昵称、变量名 |
| `Baize` / `BaiZe` | `IceCola` | 类名、驼峰命名 |
| `BAIZE` | `ICECOLA` | 全大写常量/标题 |

`b1` 只有在表示“品牌示例对象”时才改成 `ic1`；如果它表示其他业务对象（如第 6 章的 `Book`），必须保留。

### 3.2 需要覆盖的文件

1. **Markdown 源文件**（正文、代码块、注释、图片 alt）。
2. **Jupyter Notebook**：代码单元和 `outputs` 输出都要改；输出里的文字同样是可见内容。
3. **根目录旧版单页** `Python编程基础与进阶-可视化文档.html`：它不参与构建，需要单独替换。
4. **生成的资料库/手机版**：改完源文件后重新构建，不要手工编辑。
5. **截图/外部图片**：仓库内没有包含品牌词的图片；如果课件截图里有，需重新截取，无法用文本替换解决。

### 3.3 不能无脑替换的地方

批量替换后必须逐段复核语义，本次实际遇到的坑：

- **神话语境**：Notebook 输出里“白泽是能通晓万物语言的神兽”属于传说解释，直接替换会变成“冰可乐是神兽”。应改写整段输出，而不是替换词。
- **同名变量冲突**：第 6 章 `b1 = Book(...)` 是书籍对象，不是品牌实例；只改 `Baize` 类实例的变量名。
- **拼写错误**：第 3 章 `index("paize")` 中的 `paize` 是笔误，不是品牌词。改成 `icecolaa` 后仍要保证示例能触发 `ValueError`，并让注释与代码一致。
- **字符串不可变示例**：原示例靠“把 `p` 改成 `b`”演示 `replace` 返回新对象。品牌改成 `iceColaAI` 后，要改成“把 `C` 改成 `c`”，索引、打印结果、注释同步调整。
- **API Key**：示例统一从环境变量读取，禁止把真实 Key 写进 Markdown、Notebook 或 HTML。发现历史提交里有 Key，应立即到平台禁用并重建。

### 3.4 替换后的验证

```bash
# 1. 品牌词归零（排除本手册，因为手册本身记录了待替换的旧词）
git grep -n -i -E "baize|白泽" -- "*.md" "*.ipynb" "*.html" ":!docs/内容维护手册.md"

# 2. Notebook 仍是合法 JSON，代码单元无语法错误
py -3.14 - <<'PY'
from pathlib import Path
import json
for p in Path('.').rglob('*.ipynb'):
    nb = json.loads(p.read_text(encoding='utf-8'))
    for i, cell in enumerate(nb.get('cells', [])):
        if cell.get('cell_type') == 'code':
            compile(''.join(cell.get('source', [])), f'{p.name}[{i}]', 'exec')
print('notebooks OK')
PY

# 3. 重新构建并检查 placeholder
py -3.14 scripts/build_library_html.py
py -3.14 scripts/export_mobile_html.py

# 4. 手机包内也不能有旧品牌词（ZIP 不在 Git 里，需单独查）
```

说明：Notebook 中教程刻意展示的 `pip install ...`、缩进错误示例等代码单元本身不是合法 Python，`compile` 会报错，属于预期情况；重点确认没有新增的真实语法错误。

## 5. 排错速查

| 现象 | 优先检查 |
| --- | --- |
| 新 Markdown 没出现在页面 | `DOCS` 是否新增、`path` 是否正确、构建日志是否 `Skip missing source` |
| 页面打开是空白 | 文档 ID 是否重复、Markdown 是否有异常结构、浏览器控制台报错 |
| 图片显示“插图暂缺” | 图片路径是否相对当前 md、文件是否存在、是否超过 3 MB |
| 改了文字但页面没变 | 是否忘记重新运行 `build_library_html.py`，或改的是生成后的 HTML |
| 手机版还是旧内容 | 是否重新运行 `export_mobile_html.py`，ZIP 是否重新传回手机 |
| 学习计划跳转不到新章节 | `study_plan.py` 里的 `doc-*` ID 是否与 `DOCS` 一致 |
| Notebook 打不开 | JSON 是否被整体重写、引号/换行是否被破坏；优先按行做局部替换 |
